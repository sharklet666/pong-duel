# 双人乒乓球 · Pong Duel

Canvas 2D 双人乒乓球：比分板、加速球、分裂球、Web Audio 音效，
**支持两台手机在不同网络下联机**。

## 快速开始

```powershell
cd pong-duel
node start-tunnel.mjs
```

启动后会打印两个地址：

```
  本机:      http://127.0.0.1:8080
  局域网:    http://10.69.164.23:8080    (WLAN)
  公网地址:  https://xxxx-yyyy.trycloudflare.com
  ═══════════════════════════════════════
```

- **同一 Wi-Fi** → 用局域网地址
- **不同网络（手机 5G、对方在家）** → **两台手机都打开那个 `https://…trycloudflare.com` 地址**

> 公网网址每次重启都会变，重启后重新发给对方。
> 首次运行可能弹 Windows 防火墙提示，选「允许访问专网」。

## 手机打不开？先跑自检

```powershell
node doctor.mjs 8080
```

它会按可能性逐条排查，并告诉你该改哪一项：

| 症状 | 真实原因 | 怎么解 |
|---|---|---|
| `ERR_ADDRESS_UNREACHABLE` | **手机用的是 5G，不是 Wi-Fi** | 手机连上和电脑同一个 Wi-Fi |
| 同上 | 手机连了不同名的 Wi-Fi（5G/2.4G 分了两个名字） | 连同名那个 |
| 同上 | 路由器开了 **AP 隔离** | 进路由器关掉，或用公网地址 |
| 连接被拒/超时 | Windows 防火墙拦端口 | 见下方命令 |
| 只能在电脑打开 | 电脑那条 WLAN 是虚拟网卡/热点/VPN | 用公网地址 |

放行防火墙（管理员 PowerShell）：

```powershell
New-NetFirewallRule -DisplayName "Pong 8080" -Direction Inbound -LocalPort 8080 -Protocol TCP -Action Allow
```

## 玩法

**一台设备两个人**：`node server.mjs` 后点「单机双人」。
- 上半屏 P1（青色）：键盘 `A` / `D`，或上半屏拖手指
- 下半屏 P2（粉色）：键盘 `←` / `→`，或下半屏拖手指
- 两人可**同时**操作，每个手指独立跟随，互不抢控制权

**两台手机**：一台「创建房间」拿 4 位房号，另一台输房号「加入」，自动开始。

## 规则

| 规则 | 说明 |
|---|---|
| 左右墙 | 球反弹 |
| 上下边缘 | 球出去 → 对方得分 |
| 比分 | 先到 11 分获胜 |
| 加速球 | 每次击球 +4.5%，初速 640 → 上限 1560 |
| 分裂球 | 连续对拉 **8 拍**后一分为二，左右分开，最多 3 球 |
| 出射角 | 击球点越靠球拍边缘，角度越斜，可以主动打斜线 |

## 音效（Web Audio API）

全部**实时合成**，不加载任何音频文件（体积为 0）：

| 事件 | 声音 |
|---|---|
| 击球 | 方波，音高随击球横向位置变化（左低右亮） |
| 撞墙 | 三角波，短促 |
| 得分 | 锯齿波两段下行 |
| 分裂 | 上行滑音 |
| 胜利 | 四音琶音 |

移动端第一次触摸才解锁音频（iOS/Android 硬性限制），右上角 🔇 静音，多球同时撞击有压缩器防削波。

## 为什么需要服务端

两台手机各跑一份物理，球位会越差越远，像在玩两个游戏。所以联机是**服务器权威**：

- 服务器 30Hz 跑物理、广播比分与球位
- 手机只负责画 + 上报球拍位置
- 客户端插值器把 30Hz 补成 60fps 平滑运动
- 断线自动重连并回原房间
- 隧道是 HTTPS ⇒ WebSocket 自动走 `wss://`，不会被浏览器拦截

## 结构

```
start-tunnel.mjs   一键启动：游戏服务 + 公网隧道
doctor.mjs         连通性自检（手机连不上时先跑这个）
server.mjs         HTTP + WebSocket（零依赖，自实现 RFC6455 子集）
js/engine.js       物理引擎（纯逻辑，浏览器与服务器共用同一份）
js/audio.js        Web Audio 音效合成
js/net.js          联机客户端 + 状态插值
js/main.js         渲染、输入、UI 接线
style.css          响应式布局
bin/cloudflared.exe 隧道工具（52 MB，已随项目下载）
```

## 已知限制

- **公网隧道用的是 Cloudflare 免费 quick tunnel**：网址每次重启会变，不保证长期可用，不适合正式运营。
- **服务器不做反作弊**：客户端可以直接发任意 x 坐标，按「跟朋友玩」设计。
- **房间是内存态**：服务重启后房间丢失，需重新建房。
- **没有真机截图验证**：开发环境 headless 浏览器起不来（mojo 通道 ACCESS_DENIED），布局用同一套算法在 Node 里复算验证（11 种尺寸）。手感参数需真机微调。
